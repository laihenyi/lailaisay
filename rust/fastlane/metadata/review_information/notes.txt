lailaisay is a press-and-hold voice dictation utility for macOS. No account or sign-in is required. It is a menu bar app (LSUIElement) with a Dock icon; the settings window opens from the menu bar icon → 設定 (Settings), or from the setup window described below on first launch.

CHANGES IN VERSION 1.2 (BUILD 7)
The first launch is now a three-step setup window instead of the general settings window:
1. 選擇語音模型 — pick a speech model; the recommended one is downloaded once from huggingface.co, with a progress bar showing bytes and percent. A model already on the Mac is offered as an alternative when there is no network.
2. 開啟系統權限 — microphone only, with a button that opens the matching System Settings pane.
3. 試用一下 — hold the hotkey and say one sentence; the recognized text appears in the window and setup is complete.
The window can be postponed with 稍後再說 and returns on the next launch until a sentence has been transcribed. Until then the menu bar title says 需要設定 (setup needed). No new permissions, no new network endpoints and no new data collection: the only network use is still the one-time model download from huggingface.co. The AI polish feature is still absent from this build (removed in build 5).

HOW TO TEST (first launch)
1. Launch the app: the setup window opens by itself and shows 歡迎使用 lailaisay. Press 開始設定 (Start setup).
2. 選擇語音模型: keep the recommended entry or pick "small" (about 466 MB) and press 下載並使用 (Download and use). A progress bar shows 已下載 … MB／… MB (…%) until the download finishes and the model loads.
3. 開啟系統權限: only the microphone row appears. Allow Microphone access; the row turns green.
4. 試用一下: press and HOLD ⌘⇧Space, speak (Traditional Chinese or English), release. The recognized text appears in the window and the wizard shows 設定完成 (Setup complete). Press 開始使用 (Start using).
5. Open any app with a text field (TextEdit or Notes), hold ⌘⇧Space, speak, release. The status shows a green 已複製 (Copied); the transcript is on the clipboard, paste it with ⌘V. This build never injects keystrokes into other apps.

Speech recognition runs entirely on-device with whisper.cpp (Metal) or, if the user chooses it, Qwen3-ASR via the bundled transcribe.cpp (Metal). If dictation produces no speech, the status still stays green.

Earlier versions: build 6 added Qwen3-ASR as an optional model (GGUF, Apache-2.0, Alibaba Qwen team). Build 5 removed the optional AI polish feature from this build entirely, so no third-party AI service is bundled or reachable, and the App Privacy answers ("Data Not Collected") are accurate.

SANDBOX ENTITLEMENTS
- com.apple.security.device.audio-input: microphone recording while the hotkey is held.
- com.apple.security.network.client: one-time speech model download (Whisper or Qwen3-ASR) from huggingface.co (the app's only network use).
- com.apple.security.files.user-selected.read-only: importing a custom-dictionary JSON file chosen by the user in an Open panel.

Global hotkey uses Carbon RegisterEventHotKey (no Accessibility / Input Monitoring permission). Output is clipboard-only in the App Store build.
