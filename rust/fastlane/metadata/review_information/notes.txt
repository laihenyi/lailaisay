lailaisay is a press-and-hold voice dictation utility for macOS. No account or sign-in is required. It is a menu bar app (LSUIElement) with a Dock icon; the settings window opens from the menu bar icon → 設定 (Settings), or automatically on first launch.

CHANGES IN VERSION 1.1 (BUILD 6)
This update adds one more speech model choice: Qwen3-ASR (GGUF files, Apache-2.0, released by the Alibaba Qwen team), run on-device through the ggml-based transcribe.cpp library (MIT) that is bundled in Contents/Frameworks. It is a local speech-recognition model like Whisper, not an online AI service: the app still sends no audio, text or personal data anywhere. Like the Whisper models, Qwen3-ASR files are NOT bundled; the user downloads one from huggingface.co (Settings → 語音模型 → 目錄下載, entries named "Qwen3-ASR …") and picks it under 使用模型. The default flow below (Whisper "small") is unchanged and is the simplest path to test. If a Qwen model cannot be loaded, the app falls back to a Whisper model and shows the reason in the same pane. The AI polish feature is still absent from this build.

CHANGES IN BUILD 5 (response to the 5.1.1(i)/5.1.2(i) review of build 4)
This build REMOVES the optional AI polish (「AI 潤稿」) feature from the Mac App Store build entirely: the settings pane is gone and the pipeline forces polish off, so the app contains no third-party AI service and never sends any user data to one. Speech recognition runs fully on-device with the bundled whisper.cpp; the app's only network connection is the one-time model download (Whisper, or optionally Qwen3-ASR) from huggingface.co, which carries no personal data. The App Privacy answers ("Data Not Collected") are therefore accurate. The AI polish feature remains available only in the direct-download (Developer ID) build, where the user configures it explicitly; the privacy policy at the URL below now states the App Store distinction explicitly.

HOW TO TEST
1. Launch the app and allow Microphone access when prompted.
2. In Settings → 語音模型 (Speech Model), under 目錄下載 (Catalog download) keep "small" (about 466 MB) selected and click 下載所選 (Download selected). The model is downloaded once from huggingface.co into the app's sandbox container and becomes active automatically when the download finishes (the line 目前載入 shows ggml-small.bin).
3. Open any app with a text field (e.g. TextEdit or Notes).
4. Press and HOLD ⌘⇧Space, speak (Traditional Chinese or English), then release.
5. The status in the Settings window changes to a green 已複製 (Copied). Press ⌘V to paste the recognized text.

If you dictate before a model is downloaded, the status shows 需要語音模型 (Speech model needed) with a pointer to the 語音模型 pane.

Speech recognition runs entirely on-device with whisper.cpp (Metal) or, if the user chooses it, Qwen3-ASR via transcribe.cpp (Metal). The Mac App Store build has no AI polish feature and sends no data to any AI service. If dictation produces no speech, the status still stays green.

SANDBOX ENTITLEMENTS
- com.apple.security.device.audio-input: microphone recording while the hotkey is held.
- com.apple.security.network.client: one-time speech model download (Whisper or Qwen3-ASR) from huggingface.co (the app's only network use).
- com.apple.security.files.user-selected.read-only: importing a custom-dictionary JSON file chosen by the user in an Open panel.

Global hotkey uses Carbon RegisterEventHotKey (no Accessibility / Input Monitoring permission). Output is clipboard-only in the App Store build; the app never injects keystrokes into other apps.
