1.2 turns the first launch into a three-step setup: choose a speech model → allow the microphone → dictate one sentence.

• The setup window opens by itself on first launch and hands you back to the menu bar when it is done; 稍後再說 (set up later) postpones it, and it returns on the next launch
• Model downloads now show a progress bar with bytes transferred and percent complete
• If a model fails to load, the reason is shown in the window; with no network you can pick a model already on your Mac
• Until setup is complete, the menu bar title says 需要設定 (setup needed)

No new permissions and no new connections in this update. Speech recognition still runs entirely on your Mac; the only network connection remains downloading model files from Hugging Face.
