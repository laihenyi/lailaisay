# Inno Setup Traditional Chinese translation

`ChineseTraditional.isl` is copied unchanged from the Inno Setup repository,
commit `1ae7bf81dc0d2013235dfe4bb0b6f4e4a0b6b25c`:
https://github.com/jrsoftware/issrc/blob/1ae7bf81dc0d2013235dfe4bb0b6f4e4a0b6b25c/Files/Languages/ChineseTraditional.isl

The upstream license is in `LICENSE-InnoSetup.txt`. Translation credits remain
in the file header. It is bundled because Windows CI's Inno Setup installation
does not necessarily include this language. Do not depend on a developer's
locally installed language files when compiling lailaisay's installer.
